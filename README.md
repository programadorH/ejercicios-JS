# Ejercicios de Repaso - JavaScript 🚀

Repositorio destinado al almacenamiento y organización de los ejercicios de práctica correspondientes al módulo de Front-end en CESDE.

---

## 📁 Estructura del Repositorio

La carpeta principal contiene subcarpetas independientes para cada ejercicio resuelto:

```text
